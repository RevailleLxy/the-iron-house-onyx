# Sistema Administrativo Local - The Iron House (ONYX Software Systems)

Sistema web local desarrollado en PHP, JavaScript, HTML5, CSS3 y MySQL para la gestión de socios, control de accesos mediante semáforo, cobros con vigencia acumulable, planes en pareja y generación de recibos PDF.

## Instalación rápida en XAMPP
1. Copiar los archivos del repositorio dentro de `C:\xampp\htdocs\ironhouse`.
2. Iniciar **Apache** y **MySQL** en XAMPP.
3. Importar el archivo `bd.txt` en `http://localhost/phpmyadmin` para crear la base de datos `ironhouse_db`.
4. Abrir `http://localhost/ironhouse/index.php` en el navegador.
